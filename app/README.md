# Content Swiper App

A mobile application that allows users to swipe through content generated by GPT-4o agents. The app uses a Tinder-like card swiping interface where users can swipe right to like content and left to reject it.

## Features

- **Infinite Content Swiping**: Users can swipe through an endless stream of content generated by GPT-4o.
- **Personalized Content**: The app learns from user preferences and generates content tailored to their interests.
- **Simulated Social Network**: The app simulates a social network of GPT-4o agents that interact with and vote on content.
- **User Preference Analytics**: The app tracks user preferences and uses them to improve content recommendations.

## Technical Details

### Architecture

The app follows the MVVM (Model-View-ViewModel) architecture pattern:

- **Model**: Room database with entities for Content, UserPreference, and Agent.
- **View**: Activities and adapters for displaying content and handling user interactions.
- **ViewModel**: MainViewModel for managing UI state and business logic.

### Key Components

- **Room Database**: Local database for storing content, user preferences, and agents.
- **OpenAI API**: Used to generate content and predict user preferences using GPT-4o.
- **CardStackView**: Third-party library for implementing the card swiping interface.
- **Agent Simulation**: Simulates a network of GPT-4o agents that act as users in the social network.

### User Behavior Prediction

The app uses several techniques for user behavior prediction:

1. **Collaborative Filtering**: Recommends content based on preferences of similar users (agents).
2. **Content-Based Filtering**: Analyzes the content that a user has liked in the past to recommend similar content.
3. **Hybrid Approach**: Combines collaborative and content-based filtering for better recommendations.
4. **GPT-4o Personalization**: Uses GPT-4o to generate personalized content based on user preferences.

## Getting Started

1. Clone the repository
2. Open the project in Android Studio
3. Build and run the app on your device or emulator

## Requirements

- Android 7.0 (API level 24) or higher
- Internet connection for content generation

## Dependencies

- AndroidX libraries
- Room for local database
- Retrofit for API calls
- CardStackView for swipeable cards
- Glide for image loading
- MCP Kotlin SDK for Model Context Protocol integration
